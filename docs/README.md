# 尘途修仙 · 阶段 A 桌宠原型

原创 Q 版修士桌宠，Electron + React + TypeScript。此版本只验证桌面形态，不包含服务器、账号、真实修炼收益或多人游戏。

## Windows 快速启动

双击同目录的 `启动桌宠.cmd`，或启动 `release/win-unpacked/Chentu.exe`。此为未签名的免安装测试版，系统可能提示未知发布者。不需要管理员权限。不要删除免安装目录中的其他文件，也不要只复制 EXE。

本机发现默认 Chromium 沙盒启动提前退出（0x80000003）；临时 `--no-sandbox` 诊断模式可运行。这不是默认关闭沙盒的正式版本。如普通启动没有窗口，可用 `诊断启动_仅本地原型.cmd` 预览，但该入口降低进程沙盒保护，只用于本地原型，不可用于加载不可信内容。正式联网版本前必须定位此问题并恢复正常沙盒启动。

启动默认是桌宠模式，不强制置顶、不发声音。单击人物打开洞府；拖动人物移动；右键查看菜单。洞府右上角“桌宠 ↗”收起回桌宠；“−”与关闭窗口隐藏到托盘，不保留任务栏占位。点击或双击绿色托盘图标重新打开洞府，右键显示菜单。洞府固定为 440×660，切换时先解除旧尺寸约束再设置新尺寸，避免长度变化。Windows 可能把托盘图标折叠到右下角“^”内，图标位置由系统设置控制。关闭或隐藏窗口会保留托盘入口；真正结束程序请使用托盘菜单“退出”。启用鼠标穿透后，通过托盘“恢复鼠标交互”或“打开洞府”恢复。

动作与面板数值仅用于原型预览，不是真实游戏存档。隐藏后暂停动画。位置、动作、大小与置顶保存到 Electron 用户数据目录；穿透不跨重启保存，避免无法点击。

## 开发环境

建议 Node.js 22+、pnpm。用本项目锁文件安装，执行：

```sh
pnpm install
# 若安装策略禁止 Electron 的 postinstall，显式下载其运行时：
node node_modules/electron/install.js
pnpm build
pnpm test
pnpm start
```

若系统未配置 Node/pnpm PATH，需要使用实际 Node 执行 pnpm 脚本路径，并把该 Node 所在目录加入当前终端 PATH。本次开发使用 DSH 自带工具，不要求系统全局安装。

```sh
pnpm typecheck
pnpm smoke
pnpm pack:win
```

`smoke` 打开独立测试实例，使用隔离用户数据，生成 `artifacts/panel.png`、`artifacts/pet.png` 与 `artifacts/smoke-result.json`，然后自动退出。不要与正常实例同时运行，以免单实例锁让测试未执行。smoke 测试是程序行为验证，不替代人工拖动、点击和真实多屏拔插测试。

## Mac 构建与限制

在 Mac 上安装依赖并运行：

```sh
pnpm build
pnpm start
pnpm pack:mac
```

配置分别包含 x64 与 arm64，最低系统目标 14.0。构建成功不等于两个架构均经过实机验证。正式交付需 Developer ID 签名、公证及实际 Intel/Apple Silicon 测试，本项目未配置证书，不自动购买或发布。

平台相关能力集中在 `src/electron`，React 界面不直接使用 Node。主进程仅加载本地构建页面，启用上下文隔离、沙盒，禁止新窗口与任意导航；preload 只暴露有限命令接口。后续服务端接入必须建立独立业务协议，不使用桌宠动作状态充当角色权威状态。

当前 Electron 35 为原型依赖基线，不承诺长期安全维护；公网服务和正式分发前必须复核升级到当时仍受支持且覆盖目标系统的版本，并重新跑兼容测试。

## 项目结构

- `src/electron/main.ts`：窗口、托盘、有限 IPC、设置与恢复、自动 smoke。
- `src/electron/settings.ts`：偏好校验与多屏位置约束。
- `src/electron/preload.ts`：隔离桥接。
- `src/renderer/`：洞府、桌宠、原创角色与样式。
- `tests/settings.test.cjs`：设置与位置规则测试。
- `package.json`：开发、构建与三架构打包目标。
- `TEST_REPORT.md`：实际测试和未验证事项。
