# 开发进度与交接

## 需求来源

上一级目录《修仙桌宠游戏需求文档_v1.0.md》。此前只有设计；本项目开始实施阶段 A。原始需求文档中的“尚无代码”是立项时点描述，当前状态请以此文件、README 和测试记录为准。

## 当前实现

- 独立 Electron 项目，React + TypeScript，锁定依赖。
- 原创 Q 版青岚修士 SVG 与五种动作。
- 洞府面板与透明桌宠、托盘/菜单栏、拖动、置顶开关、手动穿透、大小设置、隐藏与退出。
- 本地偏好持久化，外屏移除/工作区变更位置恢复，休眠恢复事件。
- 有限 preload 接口、上下文隔离和沙盒、本地页面 CSP。
- Windows x64 与 Mac x64/arm64 打包配置。
- 单元测试与可自动退出的原生 smoke 脚本。

## 最新交接状态

用户已确认托盘修正后“好了”。原生登记和宿主回调往返已验证；当前解压版使用独立启动器+PowerShell补注册，Electron35.7.5首个图标uid=3。默认沙盒启动仍未解决，Mac未测试。完整说明、重建与备份规则见《开发交接与备份说明.md》。当前能运行的解压目录比早期ZIP新，备份时必须保留完整目录及其根级启动脚本。

## 本轮验证与限制

构建与类型检查通过，单元测试5/5通过。Windows原生程序在临时 `--no-sandbox` 诊断模式下通过桌面行为 smoke。默认沙盒启动在当前机器提前退出（0x80000003），原因未确定，阶段 A 的正常启动验收尚未完成。已提供独立诊断入口，不在普通入口关闭沙盒。Mac 未实测。详细记录见 TEST_REPORT.md。
